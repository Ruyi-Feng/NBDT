# SSM Calculator

`ssm_calculator` computes surrogate safety measures (SSMs) from trajectory CSV data and provides tools to:

- run pairwise or batch SSM analysis,
- extract trajectory segments around risk events,
- visualize event-level SSM distributions.

## 1. What This Module Does

### SSM indicator computation

Per-frame (instant) metrics:

- `TTC`
- `MTTC`
- `DRAC`
- `CAI`
- `PET`
- `2D_TTC`
- `conflict_type` (`head_on`, `rear_end`, `side_swipe`, `angled`)

Period-level (aggregated) metrics:

- `TIT`
- `TET`
- `CPI`

### Analysis modes

- `pair`: analyze one specified ego-target pair within an optional frame range.
- `batch`: scan all ego vehicles against front-neighbor relations (`left_front`, `front`, `right_front`).

## 2. File Overview

- `ssm_calculator/main.py`: main entry point for SSM computation.
- `ssm_calculator/analyzer.py`: data loading and pair/batch analyzers.
- `ssm_calculator/ssm.py`: geometry and SSM metric implementations.
- `ssm_calculator/example_config.json`: config template.
- `ssm_calculator/ssm_event_extractor.py`: extract risk-event trajectory windows from SSM JSON.
- `ssm_calculator/ssm_distribution_plot.py`: plot histogram distributions of event-level extremes.

## 3. Input Data Requirements

Expected trajectory CSV columns:

- `frameNum`, `carId`
- `carCenterXm`, `carCenterYm`
- `boundingBox1Xm`, `boundingBox1Ym`
- `boundingBox2Xm`, `boundingBox2Ym`
- `boundingBox3Xm`, `boundingBox3Ym`
- `boundingBox4Xm`, `boundingBox4Ym`
- `heading`, `speed`, `objClass`, `laneId`

Extra columns are allowed and ignored.

## 4. Run SSM Computation

Run from the project root:

```bash
python -m ssm_calculator.main \
  --config ssm_calculator/example_config.json \
  --output ./output/ssm_result.json
```

If `--output` is omitted, the result is printed to stdout.

### Config fields

Minimal required fields:

- `tracks_file`: input trajectory CSV path
- `mode`: `pair` or `batch`

Important optional fields:

- `start_frame`, `end_frame`: analysis frame range (`null` means full range)
- `lane.left_lane_offset` (default `-1`)
- `lane.right_lane_offset` (default `1`)
- `lane.lane_direction_similarity_deg` (default `45.0`)
- `period_metric.tet_tit_threshold` (default `10.0`)
- `period_metric.vehicle_class_madr` (class-wise max deceleration for CPI)
- `pair.ego_id`, `pair.target_id` (used in `pair` mode)
- `batch.relations` (used in `batch` mode; default `["left_front", "front", "right_front"]`)

## 5. SSM Output Structure

The computation output JSON is organized as:

- `meta`: run metadata (input file, mode, frame rate, configs)
- `vehicles`: nested by `ego_id -> targets -> target_id`
- `instant_metrics`: per-frame metric records
- `period_metrics`: aggregated values (`TIT`, `TET`, `CPI`)

Notes:

- `inf` values are converted to `null`.
- In `pair` mode, frame-level `relation` is filled per frame; unmatched frames are labeled `unknown`.

## 6. Use `ssm_event_extractor.py`

This script reads SSM result JSON and the original trajectory CSV, detects risk events by threshold rules, and exports trajectory windows around each event.

### Command

```bash
python ssm_calculator/ssm_event_extractor.py \
  --json_path ./output/ssm_result.json \
  --csv_path /path/to/tracks.csv \
  --metrics TTC:2.0:below DRAC:3.0:above \
  --period 50 \
  --output_path ./output/ssm_events.csv
```

### Arguments

- `--json_path`: SSM output JSON from `main.py`
- `--csv_path`: original trajectory CSV
- `--metrics`: one or more specs in `NAME:THRESHOLD:CONDITION` format
  - `CONDITION` must be `below` or `above`
  - examples: `TTC:2.0:below`, `DRAC:3.0:above`, `PET:1.5:below`
- `--period`: frames to include before and after each event (default `50`)
- `--output_path`: optional output CSV path
  - default: `{json_name}_events.csv` in the same directory as JSON

### Output CSV highlights

- `event_id`: unique event identifier
- `trigger_metric`: metric that triggered the event
- per-event extreme column:
  - `<metric>_min` when condition is `below`
  - `<metric>_max` when condition is `above`
- original trajectory rows for both ego and target vehicles within the event window

## 7. Use `ssm_distribution_plot.py`

This script plots the distribution (histogram) of event-level extremes from one or more event CSV files generated by `ssm_event_extractor.py`.

### Command

```bash
python ssm_calculator/ssm_distribution_plot.py \
  --csv_paths ./output/ssm_events.csv ./output/ssm_events_other.csv \
  --extreme_col TTC_min \
  --bins 50 \
  --threshold_line 2.0 \
  --output_path ./output/ttc_min_distribution.png \
  --title "TTC Minimum Distribution"
```

### Arguments

- `--csv_paths`: one or more event CSV files
- `--extreme_col`: event-level extreme column name (default `TTC_min`)
- `--bins`: histogram bins (default `50`)
- `--threshold_line`: optional vertical reference line
- `--output_path`: optional output image path
  - default: `{first_csv_dir}/{extreme_col}_distribution.png`
- `--title`: optional custom chart title

## 8. Recommended Workflow

1. Run `main.py` to compute SSM JSON.
2. Run `ssm_event_extractor.py` to extract event windows to CSV.
3. Run `ssm_distribution_plot.py` to visualize event-level risk distributions.
